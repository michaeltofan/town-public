CITY THUMBNAIL ASSETS

milano.png, munich.png, and arad.png are the original TOWN Feed V1 city
photographs.

cluj-napoca.svg, sibiu.svg, iasi.svg, and timisoara.svg are simple
placeholder illustrations (an initial letter on the TOWN dark palette), not
photography. No licensed or sourced photograph was available for these
cities at the time they were added, so an honest illustrated placeholder was
used instead of a fabricated "photo". Swap these for real city photography
whenever it becomes available — no code changes are needed beyond the image
file itself, since the city picker only references the file path.
